Retail Sales Analysis

📌 Project Overview

This project analyzes retail sales data to understand sales performance, customer behavior, product performance, and overall business trends.

The analysis was performed using Python, Pandas, Matplotlib, Excel, and Power BI. The objective was to clean and explore the dataset, identify meaningful patterns, and present the findings through an interactive Power BI dashboard.

🎯 Objectives

The main objectives of this project were to:

- Clean and prepare the retail sales dataset
- Explore the structure and quality of the data
- Analyze sales and business performance
- Identify important patterns and trends
- Compare performance across different categories and regions
- Create meaningful data visualizations
- Build an interactive Power BI dashboard for business reporting

🔄 Project Workflow

1. Data Collection

The dataset was obtained from the Maven Analytics Data Playground – Global Electronics Retailer dataset.

2. Data Cleaning

The dataset was inspected and prepared before analysis.

The cleaning process included:

- Checking the dataset structure
- Identifying missing values
- Checking for duplicate records
- Reviewing data types
- Converting fields where necessary
- Standardizing data for analysis
- Preparing a cleaned version of the dataset

The cleaned dataset is also included in this repository as an Excel file.

3. Exploratory Data Analysis (EDA)

After cleaning the data, exploratory analysis was performed using Pandas.

The analysis focused on questions such as:

- What is the overall sales performance?
- Which categories/products perform better?
- How does sales performance vary across different regions?
- How do sales change over time?
- Which areas of the business contribute most to overall performance?

Pandas was used to calculate and summarize the required metrics, while Matplotlib were used to visualize the findings.

4. Data Visualization

Python visualizations were created to understand patterns and trends in the dataset.

Different chart types were used depending on the analytical question, including:

- Bar charts for category/product comparisons
- Line charts for trends over time
- Other visualizations where appropriate for understanding distributions and relationships

5. Power BI Dashboard

The cleaned data was then used to create an interactive Power BI dashboard.

The dashboard provides a consolidated view of key business metrics and allows users to explore the data using interactive filters and visualizations.

The Power BI file is included in this repository.
